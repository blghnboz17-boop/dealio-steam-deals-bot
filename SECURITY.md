# Security policy

Dealio runs as a single hosted bot; only the latest release on `main` is supported.

## Reporting a vulnerability

Please report security problems privately, not in a public issue:

- GitHub: **Security → Report a vulnerability** on this repository, or
- e-mail: blghnboz17@gmail.com

Include what you found, how to reproduce it and what an attacker could reach. You should get a reply within a few days. Please don't access other users' data, disrupt the running bot, or run automated scans against it while testing.

Dealio never asks for a Steam password, cookie or login session. If someone does in Dealio's name, report it the same way.
